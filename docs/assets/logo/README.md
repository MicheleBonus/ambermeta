# AmberMeta logo

| File | Use |
|---|---|
| `ambermeta_logo.svg` | logo on light backgrounds |
| `ambermeta_logo_dark.svg` | logo on dark backgrounds ("Meta" and the M in light gray) |
| `ambermeta_icon.svg` | the drop alone: icon, favicon, avatar |
| `ambermeta_logo.png` | transparent PNG of the logo, 2466 px wide |

The drop of amber, the resin that preserves things unchanged, holds a small run chain; the M is drawn
as a protocol graph of five nodes.

- **Colors:** amber `#E8A00A`, dark amber `#CC8404`, slate `#243442` (dark variant `#E6EDF3`), white.
- **Type:** "mber" and "eta" are set in Kumbh Sans Bold (SIL Open Font License 1.1) and converted to
  outlines, so no font is needed to display the logo.
- **Origin:** the design was generated with an image model from a written prompt and redrawn as
  vector shapes; the M and the chain are circles and strokes, the drop's outline, shade, and highlight
  are traced paths.
